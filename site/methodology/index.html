Methodology

Keep the sensor pipeline easy to inspect.

The analysis is split into small steps so a result can be traced back from a model metric to the window features, filtered signal, and original sensor values.

Validation first

The loader requires all six IMU axes, timestamp, and activity fields. Sensor values must be numeric and complete before processing continues.

Sampling rate

The pipeline estimates sampling frequency from the median positive timestamp interval. If timestamps cannot produce a plausible value between 5 and 500 Hz, it falls back to 50 Hz and keeps that assumption visible in the report.

Filtering

Each accelerometer and gyroscope axis is passed through a fourth-order Butterworth low-pass filter with a default 5 Hz cutoff. The code rejects cutoffs at or above the Nyquist frequency instead of silently applying an invalid filter.

Important: 5 Hz is a project default, not a universal motion-analysis setting. Real studies should validate the cutoff against the movement and device.

Windowing

The default analysis window is two seconds with 50 percent overlap. Windows are retained only when at least 90 percent of samples share the same activity label.

Features

Each filtered axis and vector magnitude receives mean, standard deviation, RMS, range, median, and dominant-frequency features. That gives both time-domain and basic frequency-domain information without turning the pipeline into a black-box model.

Quality checks

The report counts timestamp gaps and repeated timestamps, measures exact flatline steps, and uses median absolute deviation to identify unusually extreme values for investigation.

Models

Logistic Regression and Random Forest are trained as baselines. Macro F1 selects the stronger model because each activity class should matter, even if class counts differ.

Known limitation

The chosen dataset does not list participant identity as a published variable. The baseline therefore uses a stratified window-level split. A stronger next study would use participant IDs and group-based validation to measure generalization to unseen people.
