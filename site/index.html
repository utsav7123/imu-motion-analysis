Why keep both?

The raw signal is the evidence. The filtered signal is one interpretation of that evidence. Keeping both makes it possible to inspect whether a filter removes noise or removes movement that actually matters.

Data source

Public IMU data, not company data.

The deployed analysis uses the UCI Accelerometer Gyro Mobile Phone dataset. It contains sequential accelerometer and gyroscope measurements labelled for standing and walking. The dataset is used only as a public learning and portfolio source.
